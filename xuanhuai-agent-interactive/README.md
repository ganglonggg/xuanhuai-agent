# 宣怀 Agent · 绯金绢光交互网页

本轮是可运行的完整前端交互原型，延续已确认的 A「绯金绢光」视觉，不连接后端。所有人物、课程、项目、通知与 Agent 状态均为虚构。

## 如何打开

优先双击 `standalone.html`，或运行 `open.cmd`，使用 Edge / Chrome 打开。样式、脚本、原色学院标识均已内嵌，无需安装、联网或启动服务，也不会因为漏掉 CSS 文件变成裸 HTML。

修改源码时打开 `index.html`。请保留同目录的 `styles.css`、`app.js` 与 `assets/`；不要只复制 index.html。

可选本机 HTTP 预览：装有 Node.js 的电脑在本目录运行 `node server.cjs`，打开 `http://127.0.0.1:4173`，Ctrl+C 停止。只监听本机地址，不是可发给他人的公网链接；关闭服务后可继续使用 standalone.html。

建议电脑浏览器以 100% 缩放、1440×900 或相近窗口体验。兼容响应式布局，手机底部提供四个章节入口。

## 推荐体验顺序

1. 首屏点击「先认识我」：三个问题可选快捷回答、自行输入或跳过，右侧实时呈现草稿。最后可编辑，确认后才生效。
2. 首屏输入「看看今天的 AI 活动」：跳转至筛选后的信息卡片；输入「本周课程」则展开公开课程日历。
3. 信息页切换类型、搜索、校区；打开卡片查看信息源说明、日程、未知条件；关注后可撤销。
4. 日历切换 11 月 16—22 日、23—29 日两周示例；点日期看当天安排。手机使用日期选择器＋当天安排，不挤五列长文字。
5. 合作页打开简报：「愿意进一步了解」先预览共享卡、明确授权，再进入等待态。演示控制可切换对方同意或未继续；联系授权与合作意向是两步。
6. 顶部「我」打开画像、关注、动态、账号与设置。画像可以手动编辑；「更新近期状态」必须填写明确陈述与期限，再预览、确认，可撤销。
7. 设置可减少动态效果、重置演示。也尊重操作系统的减少动态设置。

## 微交互

- 自然纵向滚动，不劫持滚轮：绢光轻视差、顶部阅读进度、导航滑动指示、章节渐入。
- 对话框聚焦光晕、首次绢光扫过、快捷入口轻抬升、发送按钮方向反馈。
- 卡片悬停及画面内的细微位移；关注图标与撤销提示；日期选中、空状态与筛选即时反馈。
- 弹层入场、背景磨砂、键盘焦点约束、Escape 关闭、关闭后回到原触发元素。
- 手机适配与减少动态模式。未宣称完成所有设备或完整 WCAG 审计。

## 数据与权限边界

- 不是实际 AI：访谈采用固定三个问题与本地状态；没有大模型、真实推荐或 Agent 间协商。
- 访谈原文、画像、合作卡和演示授权只在当前页面内存中。刷新后清空。
- localStorage 仅记录关注的示例编号、减少动态与页面内提醒偏好。未存私人访谈、课表、邮箱、电话号码或授权凭据。
- 追问只保存本地草稿，不发送负责人；没有真实报名或推送服务。
- 合作没有继续不会自动修改兴趣或能力；本人主动提供明确限制、确认临时建议后才调整近期状态。
- 即使双方愿意，也不自动交换联系方式。原型不收集、生成或发送真实联系资料。撤销后续共享不能保证收回曾真实发出的信息。
- 所有页面时间基于 2026 年 11 月的虚构样例；活动时区为北京时间 UTC+8。
- 学院标识为用户提供素材，未重新着色、重绘。正式上线仍需确认品牌使用与学院身份接入。

## 交付结构

```
standalone.html          独立完整网页，推荐直接打开
open.cmd                 Windows 默认浏览器打开入口
server.cjs               可选的本机预览服务（需要 Node.js）
index.html               分离资源的源码入口
styles.css               A 主题、响应式和微交互
app.js                   示例数据、交互与状态管理
assets/                  原色学院标识
verification.json        自动化浏览器检查结果
IMPLEMENTATION.md        后续接后端的说明
```

测试覆盖桌面与移动无横向溢出、独立资源、完整流程、用户输入转义、长期存储边界、原生鼠标与键盘、减少动态与原生滚轮。具体通过项见 verification.json；不等同于生产验收。
