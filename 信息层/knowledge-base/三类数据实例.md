# 三类数据长什么样

以下是当前数据中的真实例子，为了阅读省略了内部 ID、哈希等字段。实际保存为 JSON，另有 Markdown 目录；尚未做成网页卡片界面。

## 1. 知识卡片：一篇文章的重点与出处

| 字段 | 实际内容 |
| --- | --- |
| 标题 | 一份商业计划书，改了200多遍 |
| 发布日期 | 2026-11-13 |
| 类型 | 回顾、课程或项目介绍 |
| 摘要 | 11月6日创业实战训练课参访华芯，陈东华分享从研发转向产品与创业的经历，以及技术、产业链、工艺产能和资源协作四类壁垒；学生团队随后路演，接受需求和验证方法点评。 |
| 关联系列 | 创业实战训练课 |
| 提到的项目 | 益生酵母菌、VectoCling、诊记、荷储智控、芥智一号、Touch Uke；项目名来自配图解读，尚未人工核对 |
| 原文 | [公众号文章](https://mp.weixin.qq.com/s/fCzkzO4D3CnLts6lM-ikQA) |
| 产出的日程事实 | 无；不能由参访回顾推算下一次课程 |

它帮助回答“这次参访讲了什么”“有哪些学生项目”，并把回答指回具体文章。

## 2. 系列档案：跨多篇文章理解一门课

| 字段 | 实际内容 |
| --- | --- |
| 名称 | 创业实战训练课 |
| 类型 | 课程 |
| 关联资料 | 10 篇文章 |
| 曾用名 | X-lab创业实战课；其它文章也出现“X-lab创新创业实践课”等写法，逐条保留来源 |
| 课程形式 | 企业参访、创始人分享、团队路演与反馈 |
| 负责人线索 | 2026-11-13文章写“课程负责人李老师”；没有据此猜测全名 |
| 参与方式 | 当时文章写扫码入群、咨询课程负责人；只保留文字与原文入口 |
| 有效性 | 这些是各篇文章发表时的说法，当前负责人和参与方式仍需确认 |

实际结构中的每一条表述都有 `article_id`、逐字引用、发布日期和原文链接。它帮助回答“这门课是什么”“以前叫什么”“历年怎么参加”。

## 3. 待核对事实：一次具体安排

| 字段 | 实际内容 |
| --- | --- |
| 标题 | 科创领导力：团队管理与激发他人 |
| 类型 / 系列 | 课程 / 科创领导力 |
| 开始时间 | 2026-11-03 18:30，学校当地时间 Asia/Shanghai |
| 地点 / 校区 | 25教C416 / 卫津路 |
| 来源 | 2026-10-30《学生发来一条微信，让我坐不住了》结尾的预告 |
| 原文依据 | “团队管理与激发他人”“时间：11月3日（周二）18:30”“地点：卫津路校区25教C416” |
| 缺项 | 结束时间、主办方、主讲人或联系人 |
| 歧义 | 年份由发布日期推断；回顾段落还存在10月27日、10月28日两种写法 |
| 核对状态 | 未核对；未联系老师 |
| 是否可发布 | 否；这条已是历史安排，不能用于当前活动推送 |

它是待核对的数据记录，还不是可直接发给学生的日程。

## 三者的关系

一篇文章形成一张知识卡片，可以关联某个系列，也可能贡献多条事实。多个文章的卡片共同支撑系列档案；事实保留自己的来源、时间和核对状态。

“提炼过”不等于每条都是精华，也不等于现在仍然有效。新增 Word 汇总的46篇现已逐篇完成提炼，另见[新增文章精华](Word新增文章精华.md)；原始全文与知识卡片仍分开保存，事实候选继续标为未核对。
