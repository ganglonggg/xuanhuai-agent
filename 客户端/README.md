# 宣怀 Agent · macOS 客户端 0.6.1

宣怀 agent 是客户端的主体。打开应用就开始对话、交代任务、查看执行过程，并在对话中确认动作。资料与课程是 agent 背后的工具，应用没有课程网站入口。

0.6.1 新增真实合作预检记录驱动的自动候选、后续验证、流程启用与依据失效回退，见 [真实试用与自主改进](真实试用与自主改进.md)。创业目标工作流不推荐课程。

## 使用

新版安装到 `/Users/charles/Applications/宣怀 Agent 0.5.app`。旧版仍运行时，请先退出旧版再打开新版。两版共用原有的本机个人数据目录，更新无需重新建立会话。

构建产物位于 `dist/宣怀 Agent-darwin-arm64/宣怀 Agent.app`，支持 Apple Silicon Mac。打开 .app 即可运行，无需启动网站、浏览器或终端服务。

使用 SiliconFlow 的 DeepSeek-V4-Flash。设置中可以填写 SiliconFlow API Key 并进行实际连接测试。模型密钥只保存在运行内存中，退出后需要重新输入。会话、偏好、订阅在本机持久保存。

可直接交代任务：

- “我想做 AI 硬件，宣怀有哪些创业案例值得参考？”
- “科创领导力主要讲什么？帮我关注这门课。”
- “有哪些做机器人相关研究的导师？给我文章出处。”

## 第二版：项目与合作

工具栏新增“项目与合作”，支持需求发布、三句话意向卡、是否继续、双方许可交换联系方式和约见确认。老师也可以发布可约时间。所有操作先生成可核对的草稿，确认时检查权限和版本，草稿 24 小时后失效。

- 无需模型也可通过表单完成全部流程。老师身份仍使用本机教师口令解锁；表单中可切换学生和老师视角验证流程。
- 用对话整理项目：解锁教师身份后，在输入框模式菜单选择“老师项目合作”，描述项目及允许发布的内容。普通“对话”始终以学生身份处理合作事务，解锁本身不会将学生对话变成老师操作。
- 模型只能准备卡片，不能调用确认工具自行发布、发送意向、交换联系方式或约见。内容和可见范围由本人核对，缺失信息需补充。
- 联系方式直到双方分别批准后才互相显示；约见提议还需另一方确认。退出应用后数据保留。
- 关闭或修改需求会结束尚未建立联系的意向；已经交换的联系方式不会因关闭而收回。

完整范围、规则和限制见 [第二版实现](第二版实现.md)。

## 当前能力

- 独立 macOS 应用窗口、原生菜单、⌘N 新对话、⌘, 设置。
- 本机主进程运行 agent 工具调用循环，界面通过受限 IPC 调用；不加载任何 localhost 网页。
- 对话保存与恢复，实时显示工具执行步骤，可以停止模型任务。
- 已确认个人记忆：校区、兴趣、临时目标、忙碌时间和跨校区偏好；支持对话准备确认卡片、手动查看、删除与到期失效。
- 每周最多 5 项课程推荐：先检查真实日期、核对状态、地点、时间冲突与跨校区缓冲，再结合兴趣、近期目标和反馈排序；逐项说明原因。
- “想去并关注”“这次没空”“减少这门课程”反馈；可撤销，不将一次没空泛化为不喜欢整个方向。
- 周日北京时间 9:00 后在运行期间生成下周推荐；漏过时补生成当周，不重复生成。没有当期确认安排时显示资料不足；提供单独的历史样例预览。
- 地点缺口登记、合并、教师领取、答复待确认及确认后通知；展示四级真实进度，未确认答案不向学生提供，重新答复使旧提案失效。只在本机服务内流转，不代表已联系真实老师。
- 61 篇公众号资料检索、来源卡片；自动过滤编辑审核署名和未转录音视频的模板提示。
- 在对话中展示关注确认卡片，确认后写入个人订阅。
- 教师提交模式：解锁本机教师身份，将通知整理成修改提案，在对话里核对前后差异并确认发布。
- 客户端运行时每 5 秒检查课程变更，进入“关注的事”；macOS 允许通知时发出桌面通知。关闭窗口后应用仍在运行，⌘Q 才退出。
- 通过原生保存对话框导出 Markdown，不授予模型任意读写本机文件的能力。
- 无界面的本地公共工具服务；其他 agent 可以通过 MCP 连接。设置中可复制配置，其中包含当前个人会话的访问令牌，只应给信任的客户端。

## 架构

```text
宣怀客户端
  ├─ 主界面：对话、执行步骤、来源与动作确认
  ├─ 本机 agent：DeepSeek 工具调用、任务取消、会话持久化
  ├─ 个人侧：偏好、订阅、对话、通知状态
  └─ 公共工具服务：文章检索、课程事实、提案与变更
         ↑
    其他 agent / MCP
```

模型推理经 SiliconFlow 在云端执行。个人偏好、当前对话与相关检索片段会发送给模型；API Key 不交给渲染界面读取，不保存到磁盘。

公共工具逻辑复用 `../信息层/xuanhuai-platform/lib/`；构建时仅复制必要代码、种子课表与文章 Markdown。不复制旧网站页面、用户数据、API Key、个人令牌或教师口令。

数据位置：`~/Library/Application Support/XuanhuaiAgent/`。`private/` 保存个人数据与对话；`shared/` 保存公共课程、提案和变更；其中 `cooperation.json` 是独立的受限合作数据文件，不通过公共数据接口输出。合作工具按当前身份和参与关系返回需求、意向与联系方式。公开接口不输出个人偏好或会话。

默认 MCP 网关端口为 3210；若被占用会使用一个可用本地端口，复制的连接配置自动带入实际端口。根路径返回 404，不再提供网站。

## 开发与构建

```bash
npm install
npm start
npm test
npm run build
```

构建需要联网下载 Electron；使用本机缓存时无需重复下载。源码位于 main.js、runtime.js、preload.js、ui/。界面不启用 Node，启用 contextIsolation 与 sandbox，限制外部导航。

当前仅是本地验证版：课程仍为历史样例；没有公网服务、学校认证、邮箱推送或自动采集。推荐只使用符合条件的课程记录，尚未覆盖赛事和项目；现有历史样例不会进入正式周推送。系统通知是否出现取决于 macOS 通知设置。客户端退出期间不执行任务，重开后能获取保留下来的变更。

详细实现范围、验证和剩余缺口见 [个性化与追问实现](个性化与追问实现.md)。
