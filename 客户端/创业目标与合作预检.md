# 创业目标与合作预检 · 首版

2026-11-15。新增“创业目标”模式，普通对话与原有确认流程继续可用。

## 使用

打开 `客户端/dist/宣怀 Agent-darwin-arm64/宣怀 Agent.app`，在设置连接模型。首页点击“把创业想法变成行动计划”，或输入框模式菜单选择“创业目标与合作预检”。输入目标、已有能力、资源缺口和可投入时间。

示例：我想做面向老年人的 AI 硬件，有软件能力，每周 8 小时，缺硬件搭档，希望先验证需求。

工作流依次分析目标、检索历史案例/本人可见的已发布需求、生成 3–5 步行动计划，再为一个相关项目进行学生侧和项目需求侧预检。报告随会话保存并包含在 Markdown 导出中。“查看项目，准备意向”进入现有合作面板，选择项目、填写本人意向并确认后才能发送。

## 实现与边界

- 两个分析 Agent 使用同一云端模型的独立上下文，由本机依次编排；第二个上下文收到第一份分析进行复核。不是两个独立账号授权的远程代理，不代表教师立场，不是完整 A2A 协议或多轮谈判。
- 只使用本次输入和检索资料，不传入聊天历史。模型仍经既有 SiliconFlow 配置调用；本地指流程与存储位置，不指模型离线推理。
- 检索需求先检查账号可见范围，只投影已发布需求字段，不传入合作意向、草稿或联系方式。
- 文章用最多三个检索词查询；需求按词重合排序、最多五项。尚非向量检索或经过效果评测的语义排序。
- 来源 ID 必须存在；预检引用必须在本次目标或已发布需求中逐字找到。可能契合和冲突必须有双方证据。引用存在不等于模型推论正确。
- 分析结束再次核对需求可见性与版本，变化则报错。已保存报告是历史快照，后续合作通过既有服务重新核对。
- 无相关项目时不生成虚构预检；格式错误、假引用、取消、服务失败均显示实际状态。
- 不自动发送意向、交换联系方式、发布项目或保存偏好。0.6.0 已增加本人触发的单参数候选、固定人工回归场景评测与手动回退，见《日新三项升级.md》；留出真实用户集评测和自动回滚未实现。
