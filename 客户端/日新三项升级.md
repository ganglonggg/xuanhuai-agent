# 日新三项升级 · 0.6.0

本轮接通两个新增闭环，保留已有创业目标工作流。构建产物：`dist/宣怀 Agent-darwin-arm64/宣怀 Agent.app`。本轮没有替换 Applications 中的旧应用，也没有重启正在运行的局域网服务；网页端需自行停止并重新启动服务以加载新版。

## 围绕目标组织行动

首页“把创业想法变成行动计划”或输入模式“创业目标与合作预检”。输入目标、能力、资源缺口和投入时间；系统检索文章、符合条件的课程及可见需求，生成 3–5 步行动计划、来源及合作线索。历史文章不作为当前招人证据。该入口依赖已配置的云端模型，模型真实效果和延迟未在本轮联网测量。

## 双方授权的有限代理协作

学生向已发布项目发送意向后，双方在“项目与合作”的该意向中分别点击“填写并授权预检”。学生填写已有技能、可投入时数和参与方式；项目方填写所需技能、最低时数和参与方式。先整理并核对，再本人确认。

只有双方都确认后才生成三轮记录：学生代理提交授权卡 → 项目方代理核对 → 汇总技能、时间与参与方式的契合/冲突/待确认。技能按逗号分隔的标签精确匹配，缺少标签仅标待确认，不作能力否定。双方仍需本人决定是否继续，联系方式仍须另行双边许可。授权可以撤销，撤销后共享报告消失；已看过的内容不能从对方记忆中收回。需求更新或关闭使未建立联系的旧预检失效。

这里是固定规则代理协议，没有语言模型自由来回对话，也没有远程 A2A。创业目标报告里的双模型上下文分析仍是只读的学生侧辅助分析，不等于项目方授权。

## 可测量的推荐策略改进

“我的记忆”新增“根据反馈生成候选并评测”和“回退上一策略”。本人选择“减少这门课程”时保存该次推荐的基础分；候选算法只根据反馈基础分计算更强的同课程惩罚（最高100），不修改校区、时间、核实状态等硬过滤条件。

候选与现行版本分别在固定10条人工回归场景上运行：正确数严格提高且场景无安全违规才晋级，持平则拒绝。保存现行/候选参数、逐条结果、结论、时间及上一版本。重启后仍生效；可以回退。这个基准是开发者设计的回归集，覆盖窄范围的“减少推荐”行为，不代表真实用户满意度，不应宣传成泛化能力或生产效果提升。安全场景的过滤是评测器给定的资格，真实硬过滤仍由既有业务测试验证。

可复现示例：一门同时有 AI 兴趣 + 同校区 + 明确关注的课程，基础分11；旧惩罚8后仍为3，继续被推荐。反馈驱动候选惩罚12后为-1，不再推荐。固定回归集正确数8/10 → 10/10；其他AI课保留。这个变化是同一反馈状态下比较两个参数版本，区别于单纯前后增加记忆。
